# 跟夕走 FOLLOW THE TRAIL — 技术架构、计算规则与数据授权说明

## 1. 轨迹统计与计算规则（Section 5.4）

1. **水平距离**：采用 WGS84 地球平均半径（6,371,000 m）的 Haversine 球面距离公式逐点累加。
2. **定位漂移与异常速度过滤**：
   - 丢弃水平精度 `accuracy > 35 m` 的低质量定位点；
   - 相邻采样点瞬时速度 `> 12.0 m/s`（约 43 km/h）判定为 GPS 跳点并过滤；
   - 相邻位移 `< 1.8 m` 且 GPS 速度 `< 0.45 m/s` 时视作静止抖动，不计入轨迹里程。
3. **运动时间与休息时间**：
   - 采样间隔内速度 `>= 0.45 m/s`（约 1.6 km/h）计入**运动时间**；
   - 低于该阈值或手动暂停期间计入**休息时间**；
   - **总耗时** = `结束时间 - 开始时间`。
4. **累计爬升与累计下降**：
   - 采用 `3.0 m` 高度死区平滑滤波（Deadband Smoothing）：只有当当前海拔相对上一个锚点海拔变化超过 `±3.0 m` 时才累加爬升或下降并更新锚点，避免 GPS 垂直漂移虚增爬升。
5. **标注点距起点 / 距终点里程（Section 6.2）**：
   - 沿轨迹最近采样点累加实际折线里程计算，不使用两点直线欧氏距离替代。

## 2. 地图渲染引擎与数据来源授权（Section 4.5）

- **MapLibre（BSD-3-Clause）**：仅作为客户端矢量/栅格地图渲染引擎，不提供地图数据。
- **OpenStreetMap（ODbL 1.0）**：基础道路、水系、山峰、村庄与地名数据来源。
- **OpenTopoMap / SRTM & AW3D30（CC-BY-SA 3.0 / JAXA Open）**：等高线与地形数字高程（DEM）数据来源，支持区域打包为离线瓦片 / MBTiles 存储于本地，山区无网络环境下可离线渲染。
- **卫星影像**：在线预览使用公开影像源，离线使用须遵守对应供应商的本地缓存授权条款。
